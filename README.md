System Oceny Studentów
System Oceny Studentów jest aplikacją webową umożliwiającą nauczycielom wprowadzanie ocen, obliczanie średnich oraz generowanie rankingów dla studentów.

Funkcje PL/SQL
Funkcje i kursory do obliczeń statystycznych: Zawiera funkcje do wyliczania średnich, odchyleń standardowych i innych statystyk.

Pakiety z logiką wystawiania ocen: Pakiety zawierające procedury do zapisywania ocen w bazie danych.

Procedury kontrolujące warunki zaliczenia: Procedury do sprawdzania warunków zaliczenia kursów.

Skrypty
Skrypt tworzący bazę danych: Inicjalizuje strukturę bazy danych potrzebną do działania aplikacji.

Oddzielny skrypt do zasilania danymi demo: Wypełnia bazę danych przykładowymi danymi do celów demonstracyjnych.

Diagram Encji
Diagram encji bazy danych jest dostępny w folderze docs.

Aplikacja Web API
Aplikacja typu Web API z obsługą Open API (Swagger) dostępna pod adresem /api.

Logika aplikacji częściowo zaimplementowana po stronie bazy danych za pomocą pakietów z procedurami i funkcjami oraz widoków.

ORM i Baza Danych
Użyto technik ORM do komunikacji z bazą danych po stronie API.

Zaimplementowano mechanizmy paginacji stron dla głównych zapytań.

Autoryzacja
Autoryzacja użytkowników realizowana przy użyciu tokenu JWT.

Dokumentacja
Kod źródłowy jest szczegółowo opisany.
